Generating Dendrite Network program

Recognition of Handwritten MNIST Images Using GDN

July 2026 @M.Amano
In the networks used for deep learning, synaptic connections in the hidden layers are structured as one-to-many mappings.
Therefore, generating an "appropriate probabilistic weight space" for synaptic connections via backpropagation requires immense resources and time.

Biological neuronal networks are formed through many-to-one mappings; they lack a mechanism equivalent to backpropagation and do not require vast amounts of training data. Information is also stored in physical structures that branch out like the limbs of a tree.
Learning involves not only changes in synaptic connection strength but also the "de novo formation" and "pruning" of these branches. Feedback and inhibition are also considered to play important roles in cognition. However, the mechanisms controlling dendritic growth and the formation of connections remain completely unelucidated.

We hypothesized that a certain type of "spatial field" generated from the tips of axons guides the formation of dendrites, and we tested this hypothesis using MNIST—a large-scale database of handwritten digits commonly used for training and evaluation in machine learning.
This program (GDN) automatically generates neurons with dendrites that connect to MNIST digit patterns (0–9). When a target character is presented, the system outputs a similarity score based on mechanisms of excitation and inhibition; in the event of misrecognition, the dendritic morphology is modified.
Using five training samples per character, the recognition rate reaches approximately 60–70% after about 50 trials.

The “spatial field” that attracts dendrites

Dendrites selectively form synapses with the axon terminals of upper-layer neurons, but how they locate their targets and how their growth is guided remains unclear. Based on the following hypothesis, we constructed a model of dendritic outgrowth toward axon terminals.

  a) An activated axon terminal forms a kind of dendritic attraction field around itself.
  b) The strength of this field, like that of an electromagnetic field, follows the principle of superposition and is inversely proportional to the square of the distance.
  c) Dendrites extend from the “growth origin” (node) along the concentration gradient.
  d) When the tip of a dendrite forms a synaptic connection with the terminal of a higher-order axon, the action potential flows into the dendrite, and the field it had been generating disappears.
  e) When one axon tip becomes inactive, a field is generated by the other active axons. A new node then forms at the point where the field’s intensity is greatest, and from there, the axon “branches out” and begins to grow again.
  f) Nodes are generated as Layer 0 nodes (synaptic nodes) near synaptic connection points, and as Layer 1 nodes containing several Layer 0 nodes.
  g) In other words, Layer 0 nodes are the “leaves,” and Layer 1 nodes are the “branches.” The shape of the tree is determined by the combination of these branches. The similarity of the tree’s shape is the sum of the similarities of the individual “branches.”
  h) Learning involves the formation of new dendritic branches and the pruning of unnecessary ones.

MNIST image and dendrite network

The The MNIST image dataset (t10k-images-idx3-ubyte) consists of 10,000 28x28-pixel grayscale images with their centers aligned. GDN further converts these images into 14x14 two-dimensional arrays by adjusting the characters’ tilt and height. Each pixel is also represented as a sphere on the xy-plane in three-dimensional space, representing a synapse with the axon terminals of neurons connected to visual receptors.

GDN first uses the tip of its axon as a growth point and grows in the direction of the vector sum of all image pixels. The path is stored as a sequence of coordinates of the growth point. When a dendrite reaches a pixel, a synaptic node is created, that pixel is deactivated, the total number of pixels representing the character pattern decreases by one, and the “field” that attracts dendrites also changes.

At this stage, there is only one dendrite. Next, for all current path coordinates, calculate the vector sum to the activated pixels and set the point on the path with the maximum value as the new growth starting point (node: branching point). A new “branch” is generated from this point.

This process is repeated until all pixels become inactive, resulting in the generation of a single “digit neuron” with dendrites that reflect the branch pattern information of the target character.

Recognition and Learning

Once the “digit neuron” objects for digits 0 through 9 have been created, enter the digit to be recognized into the digit input field to perform character recognition. At this point, a target character is randomly selected from the 10,000-item MNIST database, and its image pixels are displayed within the rectangle to the right of the input field and on the x-y plane in 3D space.

GDN compares each learned character with the target character using the following procedure.

a) If a target character is present on a pixel in the training data, the information from the connected synapses travels backward through the list of growth points until it reaches one of the Layer 1 nodes. If the pixel value is 0.2 or greater, it is added to the corresponding Layer 1 node array as excitation information; if it is less than 0.2, it is subtracted as inhibition information.

b) If a target character pixel is located at a position not present in the training data, an inhibitory effect —which depends on the distance to the nearest synapse node in the training data— is generated as negative information, and the value of the Layer 1 node array is subtracted.

c) Perform the above operation for all grid points, and sum all the values in the Layer1 nod array. This becomes the output value from each “digital neuron” cell body.

d) The output values of Layer 1 nodes obtained from the recognition target represent, so to speak, the sum of the similarity of the “branches.” Local differences—such as the absence of a “leaf” at the position of a learned “leaf” or a “leaf” that is smaller than expected—reduce the values of the Layer 1 nodes, thereby lowering the similarity. If an axon terminal is present at a position where a leaf should not be, a subtraction occurs due to “inhibition.”

Recognition

After reading five randomly selected characters from 0 to 9, input any digit (0 to 9). Again, a target character is randomly selected from the MNIST database and its image is displayed to the right of the input field and in the x-y plane of the 3D space.
Our model compares each character, learned as a dendrite-linked list, with the recognition target image as follows:

The image data to be recognized is displayed as a color temperature sphere on a 16x16 grid point on the xy plane, and this image is compared sequentially with all trained characters. The dendrites of trained characters are also connected to active grid points, and if the pixel value of the target image is 0.4 (threshold) or higher, the following operations are performed:
i) A growing point connected to the tip of this axon can reach one of its layer 1 nodes by working backwards through the stored growing point list. This node is marked as reached and the total number of layer 1 nodes counter is incremented. ( The total number of layer 1 nodes varies depending on the letter, but can be between 10 and 30 )
ii) For every active lattice point, it is determined which layer 1 nodes it can reach, and if it is not a node that is already counted, the counter of the layer 1 node is incremented
iii) The above operation is performed for all lattice points of trained characters 0 to 9, and the number of activated layer 1 nodes is determined.

The number of Layer 1 nodes reached by this target character is reduced by suppression in the following case:
If a pixel value in the trained character is 0 but is greater than 0 in the target, the difference represents the degree of dissimilarity. Therefore, the number of Layer 1 nodes reached is reduced by the amount of that pixel value due to suppression.

iv)The ratio of the values of the activated and inhibited Layer 1 nodes of the character to be recognized to the total number of Layer 1 nodes of the trained characters represents the similarity, and the character with the largest value is the recognition result. (The result is displayed in textArea.)


Learning Misrecognized Digits


The GDN first loads five training data sets, calculates the average of each pixel value, and stores the results in a trained array.At this point, the basic structure of the digits has already been learned, and the recognition rate is around 50%.

In the event of a misrecognition, the GDN “learns” by adding the pixel values of the misrecognized digit to the existing array and recalculating the average. It then generates new dendrites. This causes the branches to “forks” or “prune.” As a result, the range of recognizable “shapes” expands, and the recognition rate rises to about 70% after approximately 100 trials (10 trials per digit).

Misrecognitions at this stage tend to occur with highly “abnormal” shapes. Although the GDN assigns only one neuron to each digit, it appears that it must also assign neurons to these “abnormal” shapes.

How to use a dendrite network generation App for MNIST image recognition

i) Download GDN.zip and unzip it. Open GDN.html.
ii)Load the MNIST label file (t10k-labels.bin), and then load the image file (t10k-images.bin).
iii)Click the [Train 0..9] button. Five images of “0” will be loaded at random, and the generation of dendrites will be displayed in an animation.

iv) Keep clicking until the character “9” is loaded, then finish the training. To automatically generate characters from 0 to 9 without displaying the animation, click the [Train All] button.

v)When you enter a character to verify recognition or use the increase/decrease buttons, the similarity scores and recognition results for characters 0 through 9 will be displayed in the text area. The cumulative recognition rate is also displayed each time you run the test.
or
Click the [Automatically Generate 20 Random Images] button, wait a few seconds, and the results for 20 randomly selected test characters will be displayed.
